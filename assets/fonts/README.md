# Space Grotesk

`SpaceGrotesk-var.woff2` is a WOFF2 conversion (fontTools, Brotli) of the variable
`SpaceGrotesk-native.ttf` installed on this machine, axis `wght 300–700`.

- Upstream: Space Grotesk by Florian Karsten — https://github.com/floriankarsten/space-grotesk
- Licence: SIL Open Font License 1.1 (OFL-1.1), full text in [`OFL.txt`](OFL.txt). The font may be bundled and redistributed
  with this documentation; it may not be sold on its own, and any derivative must keep the
  same licence.
- Why it is vendored: the gnosix design system (`gnosix_DS V3.4.1`) specifies Space Grotesk
  as its only typeface, and this site must render identically offline, without a Google Fonts
  request.

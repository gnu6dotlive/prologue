Vérifier un chiffre soi-même

Prenons le chiffre le plus visible du site : « 2,12× plus vite ». En cinq étapes, sans installer quoi que ce soit, vous allez le retrouver dans le reçu brut du dépôt — et voir d'où il vient.

1. Le chiffre

En haut du dossier gnostral.rs, la première case dit : « 2,12× plus vite que la version précédente du même moteur ». C'est une affirmation. Il s'agit maintenant de savoir sur quoi elle repose.

2. Le jalon

Dans le tableau « Ce qui a été mesuré », la ligne Experts empruntés porte l'étiquette Q-010. Au survol, cette étiquette ouvre une fiche : elle mène au reçu d'audit de la mesure. Tout chiffre du dossier a ainsi un jalon, et chaque jalon un reçu.

La longue suite de chiffres et de lettres est l'empreinte du commit : elle désigne une version exacte du dépôt. Le fichier lu à cette adresse ne peut pas avoir changé depuis le 29 octobre, même si le dépôt, lui, a continué d'avancer.

4. Les trois champs

Le reçu est long, mais trois champs suffisent. Ils sont rangés par longueur de réponse ; le chiffre du site correspond aux réponses de 512 jetons :

"aggregate": {
  "baseline":  { "median_tps": { "512": 9.506482 } },
  "candidate": { "median_tps": { "512": 20.179588 } }
},
"candidate_over_baseline_median_tps_ratios": { "512": 2.122718793345425 }

baseline est le moteur sans le correctif, candidate le même moteur avec. median_tps est le débit médian, en jetons par seconde, sur trois processus.

5. Refaire le calcul

20,179588 ÷ 9,506482 = 2,1227…, arrondi à 2,12. C'est exactement le rapport que le reçu écrit lui-même. Vous pouvez aller un cran plus loin : le champ per_request liste les douze réponses une à une, et les médianes se retrouvent à la main (9,51 parmi 10,12 · 9,51 · 9,51 ; 20,18 parmi 20,18 · 20,21 · 19,48).

La même vérification, en une ligne de terminal 
curl -s https://raw.githubusercontent.com/gnu6dotlive/gnostral.rs/38c4134a3a398b5b83d34326826362cf4dcc7336/evidence/runs/q010-hotpath-ssd-ab-audit-20261010.json \

Ce que vous venez de prouver — et ce que non

Prouvé

Le chiffre du site est bien celui du reçu, au commit daté. Le reçu est cohérent avec lui-même : le rapport découle des médianes, et les médianes des douze réponses.

Pas prouvé

Que la mesure s'est déroulée comme décrit. Pour cela, il faudrait la machine et le protocole. Le reçu donne de quoi les reconstituer — empreintes du modèle et du binaire, seuils déclarés d'avance, premier essai raté — mais c'est un autre travail.
